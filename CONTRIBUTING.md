# Contributing to db-lens

Thank you for contributing to db-lens! We welcome feature additions, new dataset demos, and bug fixes.

---

## Development Setup

1. **Fork & Clone**
   ```bash
   git clone https://github.com/Ayoola-tech2024/db-lens.git
   cd db-lens
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Test Suite**
   ```bash
   npm test
   ```

4. **Launch Web Studio Locally**
   ```bash
   npm start
   ```

---

## Architecture Principles

- **Zero Heavy Compilers**: Uses Node.js built-in `DatabaseSync` (`node:sqlite`).
- **Student & Non-Technical Friendly**: Clean explanations, zero jargon in the UI.
- **ES Modules**: Standard `import` / `export` syntax.
